# Project instructions

Follow the contributor guidelines and implementation constraints in
[DEVELOPMENT.md](DEVELOPMENT.md).

## Documentation during prerelease development

Werp is in alpha/beta. For all documentation changes, describe the current
behavior, settings and usage. Do not add historical notes about removed or
renamed settings, previous file layouts, migrations or legacy behavior unless
explicitly requested. Update the relevant reference directly instead of
narrating the change. Keep explanations of current design choices and relevant
compatibility/test evidence where they help the reader.

This policy applies until a stable release; the maintainer will update or remove
it when that changes.
